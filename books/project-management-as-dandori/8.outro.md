# 管理者を無くしたい

- 各員が段取りよく進めれば、理想的には専任のプロジェクトマネージャーは不要になる

# 読者が得るもの

再説明

- **段取り**: 本当のダンドリは、追加の作業を増やすのではなく、後で発生する無駄を先に潰すことである
- **自分のアイデアが通りやすい**:
  - 周囲にとって「採用するための不確実性」が十分に小さいから通る
  - プロジェクトマネジメントは「プロジェクトを進める技法」であると同時に、「人に何かを受け入れてもらう技法」でもある
- **「もったいない」を無くす**
